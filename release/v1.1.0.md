# mb3r-stack v1.1.0 integration bundle

`v1.1.0` advances the verified bundle to Bering `v1.0.0` plus Sheaft `v1.2.0`. It exposes confidence-certified failure-tolerance analysis without changing the Bering artifact contract or silently enabling an environment-specific blocking gate.

## Component pins

- Bering `v1.0.0`, model/snapshot contracts `1.3.0`
- Sheaft `v1.2.0`, multi-arch OCI image pinned by digest
- stack chart and asset pack `1.1.0`

## Added

- opt-in `failure-tolerance` values overlay for independent replica-failure and exact failed-slot sweeps
- Wilson confidence-certified minimum-boundary gate for the synthetic checkout operation
- a dedicated end-to-end check that runs released Bering `1.0.0` and Sheaft `1.2.0` binaries and verifies sweep and boundary results
- validation that chart image pins match the stack manifest

## Upgrade behavior

The default `analysis.yaml` remains schema `1.0`, warn-only, and backward-compatible. Operators opt into schema `1.2` by layering `examples/profiles/failure-tolerance/values.yaml` and must replace its endpoint id, SLO, sweep grid, trial count, and required margin with environment-owned values.

## Boundaries

This bundle verifies modelled fail-stop tolerance. It does not claim to predict capacity saturation, traffic redistribution, queues, retry-generated load, or overload cascades. Those capabilities require future additive Bering inputs plus load/chaos validation.
