# mb3r-stack v1.5.0 candidate integration bundle

This source candidate advances the bundle to Bering 1.3.0 at merged revision
`70d4145d3e26f11d8b3fb5be8917c50c1c6d8c2a`, keeps Sheaft 1.3.2, and pins
Procrustes revision `9648ae3fe9ef24725e665d008c79d0681ce40f85`.

It adds an opt-in `ebpf-otlp` profile for a producer-neutral external OTLP
source. Procrustes emits its generic report and collection plan at contract
`0.3.0`; Bering retains the logical source ID/domain and accepted raw payload,
then publishes the unchanged model/snapshot contract for Sheaft. The original
`ebpf-obi` profile remains backward-compatible.

The Bering source revision and image digest match its published
[v1.3.0 release manifest](https://github.com/MB3R-Lab/Bering/releases/download/v1.3.0/release-manifest.json).
Compatibility remains `todo-verify` until the full stack integration checks
pass and their evidence is recorded. No stack chart or asset digest is claimed
by this draft.
