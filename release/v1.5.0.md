# mb3r-stack v1.5.0 integration bundle

This published bundle advances to Bering 1.3.0 at merged revision
`70d4145d3e26f11d8b3fb5be8917c50c1c6d8c2a`, keeps Sheaft 1.3.2, and pins
Procrustes revision `9648ae3fe9ef24725e665d008c79d0681ce40f85`.

It adds an opt-in `ebpf-otlp` profile for a producer-neutral external OTLP
source. Procrustes emits its generic report and collection plan at contract
`0.3.0`; Bering retains the logical source ID/domain and accepted raw payload,
then publishes the unchanged model/snapshot contract for Sheaft. The original
`ebpf-obi` profile remains backward-compatible.

The Bering source revision and image digest match its published
[v1.3.0 release manifest](https://github.com/MB3R-Lab/Bering/releases/download/v1.3.0/release-manifest.json).
Stack compatibility is verified by
[CI run 40883389521](https://github.com/MB3R-Lab/mb3r-stack/actions/runs/40883389521)
at exact revision `1d69e898be3ae40eeffd531ec294e864dd605a31`.
The checks cover the generic source handoff, adapters, failure tolerance,
pinned-image startup, packaging, and release dry run. The bundle was published
from tag revision `4ba1d790d66c47976dc6cc05dfeb6e812427eb58` by
[release run 40886588360](https://github.com/MB3R-Lab/mb3r-stack/actions/runs/40886588360),
including anonymous public-download and packaged-preflight checks.

The external GitHub, GitLab, and Jenkins examples are pinned to the published
`v1.5.0` tag for release coherence.
