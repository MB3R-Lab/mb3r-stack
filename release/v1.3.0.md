# mb3r-stack v1.3.0 candidate

This is a staged integration update, not a verified or published release.

The target pairing is Bering 1.1.0 and Sheaft 1.3.2, plus a separately pinned
Procrustes source revision. Exact commits, published image digests and upstream
release evidence are pending. TODO pins must be replaced from the actual
release manifests before validation or publication.

The chart adds `bering.config.sources` and an opt-in `ebpf-obi` profile for an
external Linux OBI collector. Raw exports enter Bering's declared source path;
the stack does not preconstruct a graph. Bering remains unprivileged, and the
collector is not installed by this chart.

Model/snapshot schema 1.3.0 and the existing artifact handoff remain the target
contracts. Application predicates and fault assumptions stay explicit inputs.
No runtime compatibility or collector-support claim is made by this draft.

Required before promotion: finalized pins, chart/source render checks,
Procrustes handoff checks, native OTLP regression, pinned-image runtime smoke,
eBPF-source integration evidence, adapter/failure-tolerance checks, release dry
run and public asset verification. Historical compatibility entries remain
unchanged.
