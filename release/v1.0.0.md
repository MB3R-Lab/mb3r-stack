# mb3r-stack v1.0.0 integration bundle

This is the verified stack entry for the Bering v1.0.0 and Sheaft v1.0.0 major line.

## Scope

- updates the stack chart and metadata to the intended Bering `v1.0.0` and Sheaft `v1.0.0` images
- records the Bering `1.3.0` model/snapshot contract as the v1 stochastic-connectivity handoff line
- records Sheaft v1 as the consumer of the product-baseline `P_Node * P_Edge` stochastic connectivity model
- keeps the stack-level adapter envelopes on `v1alpha1`
- keeps `synthetic-otlp` as the first-user verification path

The formal model behind this stack pairing is described in the preprint [When Is a Trace-Discovered Topological Model Enough?](https://www.alphaxiv.org/abs/2607.00740).
