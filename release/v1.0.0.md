# mb3r-stack v1.0.0 draft integration bundle

This is the draft stack entry for the Bering v1.0.0 and Sheaft v1.0.0 major line.

## Scope

- updates the stack chart and metadata to the intended Bering `v1.0.0` and Sheaft `v1.0.0` images
- records the Bering `1.1.0` model/snapshot contract as the v1 stochastic-connectivity handoff line
- records Sheaft v1 as the consumer of the product-baseline `P_Node * P_Edge` stochastic connectivity model
- keeps the stack-level adapter envelopes on `v1alpha1`
- keeps `synthetic-otlp` as the first-user verification path

## Draft Boundaries

This stack entry is not verified until these are attached:

- Bering v1.0.0 release manifest and contracts manifest
- Sheaft v1.0.0 release manifest and compatibility manifest
- immutable Bering and Sheaft GHCR image digests
- stack `release-dry-run` output
- live synthetic-otlp smoke evidence
- pinned-image startup evidence
- adapter e2e evidence for GitHub, GitLab, and Jenkins

OpenTelemetry Demo remains showcase evidence, not the core readiness proof.
