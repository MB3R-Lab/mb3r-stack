## mb3r-stack v0.3.4

Candidate integration bundle that refreshes the pinned upstream pair after the Bering `v0.3.4` release and the Sheaft `v0.2.4` technical-preview release.

Included in this release:

- upgrades the bundle Bering pin from `v0.3.3` to `v0.3.4`
- upgrades the bundle Sheaft pin from `v0.2.3` to `v0.2.4`
- refreshes the stack chart, example profiles, GitHub/GitLab/Jenkins examples, adapter e2e checks, and acceptance harness constants for the new upstream pair
- keeps the stack adapter contracts on `v1alpha1`
- keeps Bering model/snapshot schema contract support on the published `1.0.0` and `1.1.0` lines
