# mb3r-stack v1.2.0

The integration bundle now includes all three stages:

- Procrustes 0.1.0: exact source pin, static-preflight launcher, and packaged instructions.
- Bering 1.0.0: unchanged published OCI image and model/snapshot schema 1.3.0.
- Sheaft 1.3.1: new published immutable OCI digest, Birnbaum importance, and
  external required-call predicates with reachable callers.

The chart, asset pack, and stack release all use version 1.2.0. Component versions
remain independent. Procrustes runs before trace collection, not as a persistent
Kubernetes service. The asset pack includes its launcher and the same stack
manifest, allowing `python scripts/procrustes.py --example` after extraction.
Git, Go 1.26.2+, Python, and initial network access are required.

The default chart remains warn-only and does not silently introduce a new SLO
or required-call predicate. Application-specific predicate configuration remains
explicit; the failure-tolerance profile still uses analysis schema 1.2.

Release verification covers packaged Procrustes ready/blocked cases and Bering
overlay ingestion, Helm lint/render, pinned-image live Kubernetes startup and
OTLP handoff, failure-tolerance checks, adapter contracts, and release packaging.
Paper experiments and their references remain outside this software repository.
